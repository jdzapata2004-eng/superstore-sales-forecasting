# Superstore Sales Forecasting

El área comercial necesita estimar las ventas totales del próximo mes para preparar su plan mensual. El objetivo del proyecto es generar ese pronóstico a partir del historial del conjunto de datos Superstore.

El alcance inicial es un pronóstico agregado para el mes calendario siguiente al último mes cerrado, sin desglose por región, categoría ni producto. La evaluación propuesta compara el error absoluto medio (MAE) con el de un pronóstico estacional ingenuo que usa las ventas del mismo mes del año anterior.

La [fase 1 de CRISP-DM](docs/crisp-dm.md) documenta los criterios de éxito, los supuestos y las decisiones pendientes. El proyecto está en fase de definición.
